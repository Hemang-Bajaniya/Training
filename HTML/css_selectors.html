CSS Selectors

CSS selectors are used to select the HTML elements you want to style.

They consist of one or more parts: an element selector, a property selector, a value selector, a combinator, and a pseudo-class selector.

  • Element selectors: h1, p, div, etc.
  • Property selectors: [href], [title], etc.
  • Value selectors: [href="https://example.com"], [title="Example"], etc.
  • Combinators: div p, div > p, etc.
  • Pseudo-class selectors: :hover, :active, etc.

Examples:

  • div p { ... } selects all <p> elements inside <div> elements.
  • div > p { ... } selects all <p> elements that are direct children of <div> elements.
  • div p:hover { ... } selects all <p> elements inside <div> elements when hovered.
