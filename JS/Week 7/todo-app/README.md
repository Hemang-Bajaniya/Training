Minimal Todo App

- Files:
  - `index.html` — main file to open in your browser
  - `styles.css` — minimal styling for tiles
  - `app.js` — add/delete/toggle + localStorage persistence

How to use

1. Open `E:\RKIT\Pre_Joining_Training\JS\todo-app\index.html` in your browser.
2. Type a todo and press Enter or click `Add`.
3. Double-click a tile to toggle complete.
4. Click the ✕ button to delete a todo.

Notes

- Todos are saved in `localStorage` so they persist across page reloads.
- The UI is intentionally minimal; tell me if you want extra features (edit, reorder, due dates).
